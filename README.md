# Spotify app Clone Project 🚀

A modern, responsive, and visually appealing web application clone built using **HTML5**, **CSS3**, and **Bootstrap 5**, integrated with custom typography and rich icons.

---

## ✨ Features
- **Responsive Design:** Fully mobile-friendly layout powered by Bootstrap grid and custom CSS.
- **Modern UI/UX:** Clean clone interface designed to replicate modern web app standards.
- **Rich Iconography:** Integrated Font Awesome and Google Material Symbols/Icons for seamless visual cues.
- **Custom Typography:** Enhanced reading experience using curated Google Fonts.
- **Interactive Elements:** Smooth navigation, button hover effects, and responsive components.

---

## 🛠️ Tech Stack & Resources Used

- **HTML5:** Semantic structure and layout.
- **CSS3:** Custom styles, layouts, transitions, and hover effects.
- **Bootstrap 5:** Responsive grid system, utilities, and UI components.
- **Font Awesome:** Scalable vector icons.
- **Google Fonts:** Custom web typography.
- **Google Fonts Icons (Material Symbols):** Modern interface icons.
